# Deliverable template

1. Context: chosen MML official tag/commit, Modelica/Dymola versions, component list, source links.
2. Model files: location and what changed (reverse/direct and diagram preservation).
3. Parameter reversal table: component | parameter | source observable | BC/assumption | reverse | direct | confidence.
4. Validation: static lint / compiler / simulation / ramp / FMU status — mark each actually run or NOT RUN.
5. Review findings: blocking/major/minor/unverified, file+line, physical rationale, proposed fix.
6. Unresolved MML4 API checks and any recommendations to get source evidence.
